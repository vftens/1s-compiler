# Демо GridCraft + 1S на www.1s-compiler.ru

Цель: посетитель лендинга за 10 секунд видит главное обещание 1S — «переезд с 1С
без страха»: загружает две ОСВ, получает список расхождений и книгу Excel.

## Что видит посетитель

```
www.1s-compiler.ru/            лендинг (статика nginx), блок «Переехали с 1С?»
www.1s-compiler.ru/demo/sverka демо сверки, ru / uk / en, без регистрации
```

1. Кнопка «Попробовать на примере» — ОСВ 1С и Odoo за январь 2025 с двумя
   заложенными ошибками (счёт 31 отличается на 100, счёта 92 нет в Odoo).
2. Или свои файлы: CSV, XLS, XLSX, ODS до 2 МБ.
3. Результат: 9 счетов / 7 сошлось / 1 расходится / 1 только в 1С, таблица,
   кнопка «Скачать сверку .xlsx» (формулы, подсветка, итоги — собирает GridCraft).

## Как это устроено

```
браузер ──POST /api/v1/demo/reconcile──▶ nginx (5 МБ) ──▶ Flask (src/demo_reconcile.py)
                                                         │ CSV: Python
                                                         │ XLS/XLSX: gridcraft-cli (Rust)
                                                         ▼
                                     JSON + /api/v1/demo/reconcile/<token> (.xlsx, 15 мин)
```

Защита публичного эндпоинта: белый список расширений, 2 МБ на файл, свои имена
файлов во временной папке (удаляется сразу), 10 запросов/мин с IP (X-Real-IP
доверяется только от локального nginx), не больше 2 процессов GridCraft
одновременно (503 «занято»), результат живёт 15 минут под случайным токеном.

Без GridCraft сервер не падает: CSV сверяется, XLS/XLSX — понятная ошибка
«пришлите CSV», кнопки скачивания нет. На странице видно, подключён ли движок.

## Как поставить GridCraft на сервер

VPS 1 ГБ не соберёт Rust (нужно ~2 ГБ RAM). Поэтому:

1. **GitHub Actions** (`.github/workflows/docker.yml`) собирает образ: стадия
   `rust:1.90-slim-bookworm` ставит `gridcraft-cli` v0.8.0, стадия Python кладёт
   его в `/app/bin` (+ лицензии в `third_party/gridcraft`). Образ публикуется в
   `ghcr.io/vftens/1s-erp:latest`, smoke-тест проверяет движок внутри образа.
2. **VPS**: `bash nginx/deploy.sh www.1s-compiler.ru` делает `docker pull`
   готового образа. Если pull не удался — собирает образ без GridCraft
   (`--build-arg GRIDCRAFT_REF=none`), демо работает только с CSV.
3. Пакет в ghcr.io после первой сборки сделать публичным
   (GitHub → Packages → 1s-erp → Package settings → Public), иначе VPS нужен логин.

Проверка после деплоя:

```
curl https://www.1s-compiler.ru/api/v1/demo/engine   # {"gridcraft": true, "version": "0.8.0"}
```
