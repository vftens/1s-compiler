# 1S Compiler — Java / ANTLR4 Build

## Prerequisites

- Java 21+
- Maven 3.8+  (or use the Maven Wrapper below)

## Quick start with Maven

```bash
cd java/
mvn package -q
java -jar target/1s-compiler-0.1.0-SNAPSHOT.jar tokens ../examples/hello.1s
java -jar target/1s-compiler-0.1.0-SNAPSHOT.jar ast    ../examples/hello_uk.1s
java -jar target/1s-compiler-0.1.0-SNAPSHOT.jar check  ../examples/accounting.1s
```

## Test the grammar without Maven (ANTLR4 tool only)

Download the ANTLR4 tool JAR once:
```bash
curl -O https://www.antlr.org/download/antlr-4.13.1-complete.jar
```

Generate Java sources from the grammar:
```bash
java -jar antlr-4.13.1-complete.jar \
     -Dlanguage=Java \
     -visitor -listener \
     -package dev.oneslang \
     -o src/main/java/dev/oneslang/generated \
     src/main/antlr4/dev/oneslang/OneSLang.g4
```

Then compile and run with the runtime JAR on the classpath:
```bash
javac -cp antlr-4.13.1-complete.jar \
      src/main/java/dev/oneslang/**/*.java \
      -d out/

java -cp out:antlr-4.13.1-complete.jar dev.oneslang.Main tokens ../examples/hello.1s
```

## What the build produces

```
target/
  generated-sources/antlr4/dev/oneslang/
    OneSLangLexer.java      ← generated by ANTLR4 from OneSLang.g4
    OneSLangParser.java     ← generated by ANTLR4
    OneSLangListener.java   ← tree listener interface
    OneSLangVisitor.java    ← tree visitor interface
    OneSLangBaseListener.java
    OneSLangBaseVisitor.java
  1s-compiler-0.1.0-SNAPSHOT.jar  ← fat JAR (includes ANTLR runtime)
```

## Grammar location

`src/main/antlr4/dev/oneslang/OneSLang.g4`

The grammar is trilingual — all three of these are valid and produce
identical parse trees:

```
// Russian
Если А > 0 Тогда
    Сообщить("Положительное");
КонецЕсли;

// Ukrainian
Якщо А > 0 Тоді
    Сообщить("Позитивне");
КінецьЯкщо;

// English
If A > 0 Then
    Message("Positive");
EndIf;
```
